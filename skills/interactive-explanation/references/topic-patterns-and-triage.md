## 3. 本質とエッジケースに気づかせる4つの足場かけ技法

1. **注目すべきプリセット（Preset Scenarios / Edge-Case Jumpers）**
   - 自由操作スライダーの近くには、必ず「典型例」「相転移が起きる閾値」「モデルが破綻するエッジケース」へワンクリックでジャンプするプリセットボタンを配置する。
   - 例：Victor (2011) の操舵角 6.5°（壁面滑走）vs 6.6°（反射跳ね返り）vs 8.0°（その場での異常ピボット回転）、Case (2017) の伝達ミス率 0% vs 5% vs 15%。
2. **破綻するトイモデル（Broken Toy Model）からの問題駆動導入**
   - 完成した複雑な機構やアルゴリズムをいきなり提示するのではなく、まず「重要な要素を1つ抜いた単純モデル」をユーザーに操作させて破綻を体験させる。
   - 例：脱進機のない時計（一瞬でゼンマイがほどけて暴走する）→ だから脱進機が必要。Greedy Best-First Search（壁の袋小路にハマる）→ だから始点からの実コスト $g(n)$ を足す A* が必要。
3. **意味的色分け（Semantic Color-Coding）と色彩抑制（Color Restraint）**
   - 現在のステップで説明している主役要素のみに鮮やかな意味的カラーを割り当て、それ以外の要素は低彩度グレーに落とす。
   - 本文中の専門用語の背景ピル、数式の変数、コードの変数、図解上のオブジェクトをすべて同一の色と `data-key` で統一し、「言葉と形の照合コスト」をゼロにする。
4. **Canvas + SVG ハイブリッド描画と決定論的連続性**
   - 高密度なフィールドや大量の軌跡は `<canvas>` で高速描画し、その上にドラッグハンドル・矢印・テキストラベル用の `<svg>` レイヤーを重ねる（Patel の Canvas + SVG Overlay パターン）。
   - ドラッグ操作中に乱数やソートのタイブレークで図が不連続にチラつく（Flicker）ことを防ぐため、シード固定と決定論的タイブレーク（インデックスや座標による一意な順序付け）を徹底する。
